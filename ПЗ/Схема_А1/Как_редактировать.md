# Диаграмма вариантов использования

Графический материал курсового проекта по дисциплине «Программирование графики и звука». Приложение А пояснительной записки содержит лист для подшивки этой схемы.

## Файлы

| Файл | Назначение |
|---|---|
| `Диаграмма_вариантов_использования_А1.drawio` | Основной редактируемый исходник для diagrams.net: отдельные овалы, подписи, связи и группы |
| `Диаграмма_вариантов_использования_А1.svg` | Векторная схема с редактируемым текстом; внутри также сохранена копия модели diagrams.net |
| `Диаграмма_вариантов_использования_А1.pdf` | Один векторный лист А1, книжная ориентация, 594 × 841 мм; шрифты встроены |

## Правка схемы

1. Откройте [diagrams.net](https://app.diagrams.net/) и выберите открытие файла с устройства. Укажите файл `.drawio` из этой папки.
2. Двойной щелчок по подписи позволяет изменить текст. Фигуры можно перемещать и менять их размер; линии связаны с актором и овалами.
3. Пользователь собран в группу из обычных фигур. Прямоугольник приложения содержит овалы и название. При перемещении группы её элементы перемещаются вместе.
4. Сохраните исходник `.drawio`. После изменения заново экспортируйте SVG и PDF, чтобы все версии показывали одинаковую схему. Сохраняйте размер страницы А1: 594 × 841 мм, книжная ориентация.
5. При экспорте SVG включите сохранение копии диаграммы. Для совместимости с векторными редакторами используйте обычный текст без HTML. Эти параметры описаны в [инструкции draw.io по экспорту SVG](https://www.drawio.com/docs/manual/export/export-to-svg/).

SVG можно открыть и в векторном редакторе: овалы, линии и текст сохранены отдельными объектами. Изменения изображения в таком редакторе не обновляют встроенную модель diagrams.net; для согласованности версий основным исходником служит `.drawio`.

Для печати используйте PDF с масштабом 100 % на листе А1. На другом размере бумаги схема будет уменьшена. Оформление выполнено шрифтом Times New Roman. Прямоугольник обозначает границу приложения; отдельные рамка листа и основная надпись отсутствуют.

## Содержание схемы

Один актор «Пользователь» участвует в восьми вариантах использования. Сплошные линии обозначают его участие в действиях приложения. Названия действий показывают цели пользователя; подробные алгоритмы раскрыты в разделах 2–3 записки.

| Действие | Что охватывает |
|---|---|
| Открыть аудиофайл | MP3, WAV, OGG Vorbis; системный диалог и перетаскивание |
| Включить демонстрационную запись | Встроенный фрагмент «Спектральный этюд» |
| Управлять воспроизведением | Пауза, продолжение, перемотка, громкость |
| Наблюдать трёхмерную визуализацию | Форма объекта, цвет и свечение, связанные со звуком |
| Выбрать режим деформации | «Все», «Пульс», «Волны», «Рябь» |
| Настроить внешний вид | Цвета, силы эффектов, направление волн, движение, сброс оформления |
| Изменить ракурс объекта | Вращение, масштаб и сброс ракурса |
| Переключить режим просмотра | Скрытие панелей и возврат к обычному интерфейсу |

Обозначения акторов, вариантов использования и границы системы соответствуют нотации [UML](https://www.omg.org/spec/UML/2.5.1/). Описанные действия сверены с текущими `scripts/main.gd` и `scripts/audio_controller.gd`.
