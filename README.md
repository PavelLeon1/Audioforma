# Аудиоформа

Курсовой проект по дисциплине «Программирование графики и звука». Приложение разрабатывается в Godot 4.7.2.

## Запуск проекта

1. Подготовить локальную копию Godot командой `./tools/setup_local.ps1`. По умолчанию скрипт берёт редактор из указанной для курсового проекта папки; другой каталог можно передать параметром `-GodotDirectory`. Папка `.local/` не входит в Git.
2. Запустить проект командой:

   ```powershell
   .\tools\run.ps1
   ```

3. Нажать «Воспроизвести» для демофрагмента или «Открыть аудио» для MP3, WAV либо OGG Vorbis. Откроется системное окно выбора файла; аудиофайл также можно перетащить на окно приложения. Кнопка «Демо» возвращает встроенный фрагмент. Пробел приостанавливает и продолжает воспроизведение с той же позиции. Сообщения о загрузке и состоянии звука показываются под кнопкой.
4. Выбрать режим деформации кнопками под объектом или клавишами 1–4: «Все», «Пульс», «Волны», «Рябь».
5. Вращать объект перетаскиванием левой кнопкой мыши. Колесо или кнопки «−» и «+» меняют масштаб; кнопка «Сброс» или клавиша R возвращают исходный ракурс.
6. Кнопка «Настроить вид» или клавиша S открывает настройки цветов, свечения, контура, общей и раздельной реакции частот, направления басовой волны, краткого увеличения сферы и тряски камеры, чувствительности басовых ударов, скорости движения и автовращения. Форму настроек можно прокручивать. «Сбросить» восстанавливает исходный вид. Изменения применяются сразу и сохраняются автоматически.
7. Кнопка «Просмотр · F» или клавиша F скрывает все панели и переносит сферу в центр. В этом режиме можно вращать её мышью в любой части окна, менять масштаб колесом, ставить звук на паузу пробелом и выбирать режимы клавишами 1–4. F или Esc возвращают интерфейс и прежний масштаб.

Скрипт запуска сначала импортирует ресурсы, затем временно направляет пользовательские данные Godot в `.local/profile/` и восстанавливает прежние переменные окружения после завершения. Демонстрационный звук хранится в `assets/audio/demo.wav`. Его можно создать заново командой `python tools/generate_demo.py`; для генерации используется только стандартная библиотека Python.

Три индикатора показывают текущую активность басов (20–250 Гц), середины (250–2000 Гц) и высоких частот (2000–8000 Гц). Анализ выполняется средствами Godot во время воспроизведения. Пространственный шейдер в `shaders/orb.gdshader` деформирует тёмную сферу; второй кодовый шейдер в `shaders/halo.gdshader` рисует светящийся контур той же формы. Басовые удары запускают направленную бегущую волну, короткое увеличение сферы и тряску; средние частоты создают крупные волны, высокие — рябь. Соотношение частот задаёт цвет, а общая громкость — яркость свечения.

Настройки сохраняются в `.local/Audioforma.ini` при запуске из проекта и рядом с `Audioforma.exe` в автономной сборке. Глобальная установка не требуется.

## Проверка

```powershell
.\tools\test.ps1
```

Проверки используют синусоидальные сигналы 80, 800 и 5000 Гц в `tests/fixtures/`, а также закодированные версии сигнала 800 Гц в MP3 и OGG. WAV-файлы можно создать заново командой `python tools/generate_test_tones.py`. Тесты также проверяют басовые удары на демофрагменте, направление волны, пульс и тряску с затуханием, уровень громкости, передачу параметров в шейдер, переключение режимов, режим просмотра, паузу с сохранением позиции, управление ракурсом, перетаскивание файлов и сообщения для повреждённого или неподдерживаемого файла.

## Сборка Windows EXE

Шаблон экспорта Godot 4.7.2 загружается в `.local/godot/editor_data/` без установки на компьютер. Скрипт получает из официального архива только Windows x86_64 шаблон с помощью стандартной библиотеки Python:

```powershell
python tools/setup_export_template.py
.\tools\build.ps1
```

Готовое приложение — `dist/Audioforma.exe`. Звук, сцена и шейдер встроены в этот файл; для запуска на Windows x86_64 достаточно самого EXE. Скрипт сборки проверяет состав ресурсов и запускает копию EXE из отдельной папки без редактора. Каталоги `.local/` и `dist/` исключены из Git.
