# Аудиоформа

Курсовой проект по дисциплине «Программирование графики и звука». Приложение разрабатывается в Godot 4.7.2.

## Запуск проекта

1. Подготовить локальную копию Godot командой `./tools/setup_local.ps1`. По умолчанию скрипт берёт редактор из указанной для курсового проекта папки; другой каталог можно передать параметром `-GodotDirectory`. Папка `.local/` не входит в Git.
2. Запустить проект командой:

   ```powershell
   .\tools\run.ps1
   ```

3. Нажать «Воспроизвести» для демофрагмента или «Выбрать файл» для MP3, WAV либо OGG Vorbis. Кнопка «Демо» возвращает встроенный фрагмент. Мышью можно вращать объект, пробелом — управлять воспроизведением.

Скрипт запуска временно направляет пользовательские данные Godot в `.local/profile/` и восстанавливает прежние переменные окружения после завершения. Демонстрационный звук хранится в `assets/audio/demo.wav`. Его можно создать заново командой `python tools/generate_demo.py`; для генерации используется только стандартная библиотека Python.

Три индикатора показывают текущую активность басов (20–250 Гц), середины (250–2000 Гц) и высоких частот (2000–8000 Гц). Анализ выполняется средствами Godot во время воспроизведения.

## Проверка

```powershell
.\tools\test.ps1
```

Проверки используют синусоидальные сигналы 80, 800 и 5000 Гц в `tests/fixtures/`, а также закодированные версии сигнала 800 Гц в MP3 и OGG. WAV-файлы можно создать заново командой `python tools/generate_test_tones.py`. Шейдерная деформация, режимы и экспорт Windows EXE запланированы на следующие итерации.
